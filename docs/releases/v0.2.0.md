## Breaking changes

- Start with `--mailbox-root` pointing to an existing absolute directory.
- Register with an empty JSON object at `POST /api/2026-11-05/registrations`.
  The response contains a UUIDv4 `id` and an absolute `directory` whose basename
  matches that ID. No process ID is required or returned.
- Use the dated prefix for message uploads and deletion. Retired unversioned
  routes and unsupported dates return `404 unsupported_api_version` and name
  the supported prefix.
- Re-register after restart. Deletion and restart preserve mailbox directories
  and files. Retire the registration before cleaning up an owned mailbox.
  Lost registration responses can leave orphaned directories.

The operator provisions the root and permissions. On Windows the planned
installer supplies `C:\ProgramData\localpost\mailboxes` and inherited ACLs must
permit service and agent access. POSIX directories use `0700` and files `0600`.
The daemon and consuming agent run under the same UID. Docker mounts the root
at the same absolute host and container path. These are deployment choices,
not an implicit daemon root.

See the [migration instructions](../../README.md#migrating-from-v010) and
[container guide](../containers.md). FGA Dev M08, localswim V2 Dev M07 and
Drive Stats Dev are planned recipients of rollout notices.
